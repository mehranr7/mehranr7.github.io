## 🌐 About This Repository

This repository contains the HTML, CSS, and JavaScript that power my personal website. It serves as a central hub for my professional experience, education, technical projects, and certifications.

### Features
- **Bilingual Support:** Fully localized in English and German, contained within dedicated `/en` and `/de` directories.
- **Smart Routing:** The root `index.html` uses a lightweight JavaScript router to automatically detect the user's browser language and redirect them to their preferred localized version.
- **Responsive Design:** A custom, lightweight CSS grid layout that adapts seamlessly to mobile, tablet, and desktop viewports.
- **Modern Aesthetic:** A clean, professional, and accessible grayscale color palette.
- **Direct Resume Access:** Quick download links for my latest PDF CVs in both English and German.
